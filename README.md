# StudyGenie

StudyGenie is an AI-powered study planner developed using:

- HTML
- CSS
- JavaScript
- Java
- Javalin
- SQLite

Features:
- User Authentication
- Subject Management
- Exam Tracking
- Timetable Generator
- Tasks & Progress Tracker
- Reminders
- Profile Management
- Pomodoro Timer

Developed as a B.Tech Mini Project.
